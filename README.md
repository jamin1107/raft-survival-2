# 木筏求生2 - Raft Survival 2

> 基于《木筏求生(Raft)》的网页游戏续作，支持手机端触控操作。

## 在线游玩

直接用浏览器打开 `raft2.html` 即可游玩，无需安装任何依赖。

## 游戏特色

### 核心玩法
- 🪝 **钩子收集**：投掷钩子捕获海上漂浮的木板、塑料、棕榈叶等资源
- 🍖 **生存管理**：实时管理生命值、饥饿值、口渴值
- 🏗️ **木筏扩建**：从3×3小筏发展成海上家园
- 🦈 **鲨鱼防御**：鲨鱼定期啃咬木筏，用木矛攻击击杀

### 主线任务系统（7章剧情）
1. **第一章：漂流之初** - 收集资源，建立基本生存保障
2. **第二章：站稳脚跟** - 扩展木筏，建造蒸馏器和烤架
3. **第三章：击退威胁** - 制作武器，击败第一只鲨鱼
4. **第四章：科技启蒙** - 建造研究桌，解锁科技配方
5. **第五章：信号追踪** - 制作接收器和天线，追踪神秘信号
6. **第六章：扬帆起航** - 建造帆架，驾驶木筏前往信号源
7. **终章：求救信号** - 制作并放置信标，等待救援到来

### 丰富建造系统
- **生存设施**：蒸馏器、烤架、种植园、研究桌、收集网、矛架
- **新增设施**：储物箱、床铺、熔炉、鸟巢
- **科技建筑**：接收器站、天线塔、帆架、信标台
- **地板类型**：木地板、金属地板（鲨鱼咬不坏）

### 续集新特性
- 🌤️ **天气系统**：晴天、多云、雨天、暴风雨
- 🌙 **昼夜循环**：夜晚视野受限，需要火把照明
- ⛵ **航行系统**：建造帆架后可驾驶木筏航行，罗盘指引信号方向
- ⬆️ **升级系统**：钩子3级、矛2级
- 🏝️ **岛屿探索**：随机出现的岛屿
- 🐢 **海洋生物**：海龟、水母、鲸鱼、海鸥
- 🏆 **成就系统**：8个成就

## 操作方式

### 电脑端
| 按键 | 功能 |
|------|------|
| WASD/方向键 | 移动 |
| 鼠标 | 瞄准 |
| 左键 | 投钩/攻击 |
| E | 互动 |
| B | 背包 |
| C | 制作 |
| Tab | 建造 |
| Q | 任务 |
| G | 升/降帆 |
| R/F | 调整航向 |
| 1-6 | 切换工具/食物 |
| 空格 | 投钩 |

### 手机端
- 左下虚拟摇杆移动
- 右下按钮投钩/互动
- 顶部图标打开背包/制作/建造/任务

## 技术栈

- HTML5 Canvas
- 纯JavaScript（无框架依赖）
- 响应式设计，支持手机触控
